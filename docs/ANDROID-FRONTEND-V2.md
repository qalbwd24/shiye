## 用户最新确认的进入流程

2026-10-17 用户补充：像 QQ/微信一样默认先进入会话列表（包括置顶），点击会话后再进入消息列表/发送。长日记独立入口位置尚未最终决定，但必须分别提供快捷写与浏览阅读入口，不能要求从阅读列表找到篇目后才能编辑；希望支持类似一本日记“开屏直接新建写日记”。

本次暂用底部 **随想 / 写日记 / 思绪** 供实际试用：随想为会话列表；中间写日记直接新建并编辑；思绪为篇目阅读列表、进入后可继续编辑。提供启动页选项“会话列表（默认）/直接新建日记/继续上次页面”。这是本轮可调整的入口安排，不当作用户已确定的永久位置。

## 本次交付目标

- 思绪：根据原版实际观察调整正文优先、空标题按需显示、紧凑元数据、键盘工具栏、保存反馈、阅读与继续编辑；保留拾页共享 richdoc 编辑核和稳定媒体身份。
- 随想：优先把已有冻结 Telegram Web A 本地化前端的移动界面放入 Android 壳，复用成熟消息列表、编辑/回复、输入和媒体交互，不再扩展第一版手写气泡。原生平台桥负责照片选择和系统返回。
- 运行：覆盖更新电脑主模拟器的样机，不占用手机；保留第一版 SQLite/媒体数据，并提供原记录入口。新 Telegram 对照层只用其独立 IndexedDB 作为聊天权威，不与 SQLite 双写。

## 已确认需求

- 默认会话列表及快捷写日记、思绪阅读入口保持；随想与思绪的设置分别位于各自页面。
- 会话可选自己的背景；背景派生头像沿用电脑中心裁切缩略图规则。以手机可视区适配，不改正文数据。个人会话／群会话需对齐已有类型，不把 UI 标签当联网或群成员服务已完成。
- 会话管理跟进电脑版最新“使用中／已归档”、置顶、归档和恢复。归档保留稳定 ID、正文、草稿及媒体，待发附件／编辑保护不能省略。不得通过 CSS 隐藏虚拟列表行或另造一套权威存储伪装对齐。
- 主页支持明确的主动刷新反馈，考虑下拉刷新；重复触发合并，避免每次重建页面。自动刷新与刷新速度需要区分真实业务变更和渲染性能，后者另做交接。
- 消息统一圆角矩形，去尾角；纯表情不漂移、不与时间戳重叠；时间戳与普通气泡一致。消息字号、气泡内留白和最大宽度可设置。
- 发送按钮常驻；无可发送内容时禁用，保留可访问提示。
- 表情选择面板位于底部输入法区域，避免挤压输入框。为将来本地表情包库保留入口，本轮不擅自增加远程贴纸服务。
- 附件入口先显示最近照片，可在同网格选择视频；普通文件另有入口调用系统文件管理器。保留权限拒绝／部分授权／空态／加载失败与取消处理。

## 本轮实现边界

外观偏好与正文独立，未知偏好字段保留；图片不得以大块 data URL 塞入偏好。背景文件由原生保存到私有目录，偏好只保存资源引用。背景不作为日记附件或改变事件时间。

冻结 ui18 worker 尚无电脑 ui25/26 的归档事务能力。需先核对完整依赖；若无法安全共用，本轮标注未接入而不伪造归档成功。新增云服务绑定也只遵循现有接口文档，不提供假连接。

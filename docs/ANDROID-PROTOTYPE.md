## 第一版（0.1）实现边界

源码位于 `android/`，是独立 Android 项目，不变更桌面运行程序或正式日记。样机先使用 Android 原生 Java Views 外壳与 SQLite、局部 WebView 承载现有 richdoc 编辑核；不是 Compose 实现。选择已有可用工具链以先验证交互/数据，不因技术选型反复推迟双入口体验。

包名 `dev.shiye.app`，显示名“拾页 · 样机”，只安装电脑 `emulator-5554`。首轮内置虚构示例，不导入私人日记，不连接电脑 API 或服务器，无 INTERNET 权限。后续用户在样机录入的内容保存在该独立应用私有库，不与电脑版自动同步。

| 能力     | 本轮目标                                                                                                             | 与电脑端关系                                                               |
| -------- | -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 思绪     | 日记列表、分类筛选/搜索、新建、标题/日期/分类/标签、整篇富文档编辑和阅读、自动保存、正文图片、实际缩进/格式/撤销重做 | 使用相同 richdoc v1 正文与块/媒体出现身份；不复制电脑整页 UI               |
| 随想     | 会话列表、新建/改名、自聊发送、逐会话草稿、图片、回复、复制、撤回/重新编辑、本地重开                                 | 稳定消息身份、发送提交后清草稿、共同富文档正文、撤回墓碑；不引入外部IM账号 |
| 保存     | SQLite 事务、revision 冲突检测、幂等发送、私有媒体和 SHA-256                                                         | 一份权威正文，不另存可编辑 HTML/Markdown 副本                              |
| 手机体验 | 原生系统栏/键盘布局、整页长文、移动格式工具栏、阅读/编辑切换、系统选图、长按消息菜单                                 | 以长文写作和短消息记录两种操作分别设计                                     |

首轮不承诺电脑端所有功能完整对齐：聊天自动归篇/思绪互相投影、旧格式导入、完整备份恢复、历史版本、全库搜索和复杂设置仍需后续逐项补齐。样机提供本地 ZIP 导出，尚无恢复入口；不能当成电脑版备份格式已兼容。未来正式同步还需对端接口和统一消息层版本约定。

一本日记原版1.96.55已在独立断网API30 AVD实际观察首页、新建、标题按需、输入/工具栏、缩进、返回保存、阅读/继续编辑及简洁模式。详见[逐页记录](ANDROID-REFERENCE-REVIEW.md)。这是参考熟悉，不代表当前样机已达到原版长文体验；原版相册导入、Markdown和全部设置分支未完整验证。

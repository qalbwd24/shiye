## 本地边界

Windows WebView2 使用虚拟主机 `shiye-preview.local` 映射本机构建目录，未启动 HTTP 服务。页面 CSP、页面和数据 Worker 的 fetch/XHR/WebSocket 等传输限制、原生资源/外链拦截共同约束联网。数据使用本地适配客户端，网络请求类型名称沿用上游内部接口，但没有 Telegram 网络客户端连接。

预览持久数据在 `var/telegram-chat-preview/webview/`；窗口偏好在同级 `window.json`。自动验收另用 `tmp/telegram-preview-20261015/verification-profile/` 和 `verification-window.json`。此前试运行的 `tmp/telegram-preview-20261015/user-profile/` 保留，可供恢复，不清理或覆盖。外观偏好在各自 profile 的 localStorage，不复制正式资料、日记或密钥。正式集成时再确定本地消息 schema、媒体/备份及跨端协议。

## 当前复用事实

Android APK 直接复用电脑端8个编辑核心文件（7 JS +1 CSS）及逐包许可证，9项SHA与源文件匹配。包含实际 Tiptap 编辑器、rich-body-adapter、rich-document校验、剪贴板/日期辅助与样式，并非独立另写编辑核心。

原生 SQLite、列表/聊天外壳与附件面板是本轮新写的最小验证层，当前没有移植 Telegram 原生聊天/附件源码。它们已验证本地数据可用，但不能因此宣布长期路线已选定。后续应先评估桌面既有 Telegram Web A 的移动适配/本地worker和 Telegram 原生组件，减少自写聊天范围。详见 [复用审计](../outputs/2026-10-17-android-dual-prototype/reuse-audit.md)。

# 缩略图与窄窗口 ui8 · 2026-10-16

用户要求消息图片缩略图更小、降低聊天窗口过宽的最小宽度，对应需求U27。

随后追加U28关闭语音按钮、U29发送纯表情卡顿／位移、U30默认Esc立即切换（保留原列表可选）及会话排列、U31每会话独立背景与气泡等外观；本轮ui8统一处理，所有会话继续维护对应开发文档。

## 实现

聊天单张图片／视频缩略图限制在240×220 CSS像素，保持原比例；图组整体限制280×260，保留原有组内排列。尺寸不随文字缩放增大，原图像素、媒体文件和独立图片窗口不缩小。

原生聊天窗口最小宽度从700降至360 DIP，最小高度仍600 DIP；PreviewWindow.MinimumDip统一构造、边缘拖动、DPI适配、窗口恢复、每屏记忆及验证视口的宽度约束。尊重已有窗口尺寸，用户自行缩窄后按当前屏保存，不在升级时强行缩小。

空输入移除语音入口及宽度占位，非空仍显示发送。纯表情在本机临时消息阶段按正文提前确定形状／时间栏位置／渲染器，避免确认后emojiOnlyCount才补齐导致变形；由本机页脚感知的跟随逻辑处理发送定位，禁用与它竞争的上游发送／收回位置动画，保留原生吸附动画和其他交互。

默认Esc按排列立即切换，原预选列表与方向键、等待仍可从设置选择。设置→会话切换与排列提供上移／下移并以稳定ID保存，同时用于侧栏和Esc；快速连按串行保存各自草稿。对话设置→本对话外观可以独立明暗、背景遮罩、气泡透明度、圆角和间距，默认继承全局，取消只删除该会话的覆盖项；窗口和字体继续按屏记忆。

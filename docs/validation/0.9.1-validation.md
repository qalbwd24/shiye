## 当前可用流程

1. 在原版安卓“一本日记”导出包含媒体的完整备份，在拾页的“备份与导入”导入并核对内容。
2. 在“云同步”填写 WebDAV 根地址、用户名和密码，先点“测试连接”。
3. 云端为空时点“合并并同步”，电脑库会成为第一份云端数据；之后手机和电脑读取同一份安卓兼容数据。
4. 后续同步只上传新增或变化的媒体和必要的 `diary.json`；遇到同一稳定标识的不同版本会先暂停，让冲突管理保留选择。

## 流量边界

- 首次迁移：上行约为 `diary.json` 大小加新媒体总大小，下行约为云端 JSON 和合并所需媒体。
- 无变化：强 ETag 可将 JSON 拉取压缩为 304 响应；本地投影一致时不 PUT JSON，也不传媒体字节。
- 文本变化：上传新的完整 `diary.json`，未变化媒体不重复上传。
- 新媒体或媒体内容变化：只上传对应媒体；原版手机仍按自己的全量 JSON 逻辑工作。

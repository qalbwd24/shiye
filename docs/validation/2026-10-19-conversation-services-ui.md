# 会话内程序设置 UI

## 需求与实现

用户要求：朝花夕拾是会话可接入的一个程序，先进入会话自己的资料/外观设置，再进入该程序开关与参数。会话之间独立、同会话多个窗口共用；已有消息、评论和推送进度保留。用户先要求候选/预览，随后明确另一性能会话已结束，可以继续界面更新。

本轮基于已启用ui40，只修改`shiye-preview.js`、`shiye-preview.css`并增加`shiye-conversation-services-ui.js`。设置首页统一导航到当前会话；移除原固定房齿轮直接跳到全局程序参数的特殊分支。资料/外观、程序接入和嵌套参数分别保存，返回保留草稿，服务控件不混入普通会话FormData。参数页有显式推送开关、模式、时区、分类，历史范围/身份折叠；保存期禁止输入被迟到回执覆盖，409保留草稿。

现有固定朝花夕拾会话使用原真实桥，没有创建/迁移/重新绑定。其他会话目前只有UI和可注入适配口，缺少原生桥/worker通道时明确提示且禁止保存；不能将合成预览的成功当作正式多会话接入完成。完整接缝和后续职责见[UI端口](../CONVERSATION-SERVICES-UI-PORT.md)。

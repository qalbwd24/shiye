## 实现

- 气泡取消三角尾巴，调节底色／默认不透明度与消息间距；消息间距可调。侧栏及折叠按钮随消息左右对齐镜像。
- 发送后跟随消息末尾，监听媒体／输入高度变化并增加底部空间；用户滚轮操作会取消自动跟随。输入框可拖动上沿调整高度并记忆。
- 依据最新修订，输入区无论是否为空均取消 ↑↓ 直接切换，且本地输入不触发上游 ↑ 编辑上一条消息。仅 Esc 唤起列表，连按向下选择，菜单内支持 ↑↓／Enter；用户确认先试用 800ms。外观设置可调 400–3000ms；关闭／失焦清理计时，保留草稿并恢复末尾。命令／模态／输入法优先。
- emoji 与本地表情包按频次排序，网格方向键／Enter 操作，初始焦点为素材。emoji 成功插入计数，表情包确认发送计数。列表首次读取重试以适应 Worker 初始化。
- 修复消息右键菜单读取不存在 MiddleHeader 的异常；菜单关闭后普通 Esc 切换仍可用。
- 图片使用独立原生窗口，等待原图数据后经本机分块桥打开；支持鼠标位置滚轮缩放、拖动、适应／原尺寸、复制、另存、Esc 关闭。修复本地客户端全尺寸请求未指定缩略图类型时取不到原图的问题，避免只放大缩略图。128 MB 为当前独立查看器传输上限，失败保留内嵌查看。
- 修复原生底角热区遮挡 WebView；窗口越界纠正、左右优先吸附、沿边 240ms 收起／展开、6 DIP 露边、悬停与快捷键恢复。输入法／菜单／输入活动时延后自动收起；多屏接缝不作为隐藏边。
- Ctrl＋滚轮／加减每步 4% 只改变消息和输入文字，Ctrl＋0 复位；原生 WebView 保持 1，图标、工具栏和图片确认控件不同比放大。旧整页比例迁为 TextScale。
- 群聊只预留 shiyeProgramPort v1 的 connect／send／subscribe 适配边界；未连接明确失败，不伪造实际程序收发。
- 工作区、DPI 和显示变化后重排及纠正位置；最小尺寸封顶为当前工作区。图片窗同样纠正越界。标题字号未变时不创建／释放等值字体，修复 Font.GetHeight 参数无效。

本轮查出的相邻问题：空输入 ↑ 被上游当作编辑上一条消息；输入高度误施加到消息；取消表情包后普通图片误计频次；按钮在 mousedown 已确认而 click 统计未执行；图片取消过渡期主编辑器短暂重建。分别用输入规则、CSS 作用域、取消跟踪、实际确认入口事件及可重试末尾聚焦处理，并纳入隔离检查。

# 0.9.8 启动主题验收（2026-09-30）

## 原因与修复

原先在获取日记库后才由应用模块设置 data-theme，静态 HTML 没有已保存的主题信息，默认底色为浅色。快捷原生窗口和 WebView 未载入时也使用浅色背景。

服务端现在向 HTML 注入严格白名单的 theme preference，文档头同步脚本和关键底色样式先于应用模块运行。快捷页的 body 类也在 HTML 中确定，避免先显示主窗布局。原生窗口在创建时通过小型主题提示读取选项，系统模式读 Windows 应用主题；在网页就绪前显示相同底色。首屏主题监听在正式控制器接管时解除。

新增公开 `GET/HEAD /startup-theme.json[?quick=1]` 只返回 `{theme: light|dark|system}`，与未解锁 HTML 中的显示选项一致，不返回日记、附件标识或其他偏好。仍不开放受本地锁保护的库与媒体端点。原生请求失败回退到系统主题，700ms 超时。

- 完整 `npm run check` 通过，223 项测试，0 失败、0 跳过；含文件依赖、ESLint、Prettier。日志 `var/check-0.9.8.log`。

- 新建进入 CodeMirror，源码与 HTML 投影匹配，保存后切篇、重载仍可编辑。
- 标题、粗体、任务标记、引用、代码与删除线显示；日期方括号不会被当成链接隐藏。源码切换保留撤销／重做。
- 普通段落 Enter 空两格、列表 Enter 续项；Ctrl+B、Tab、Alt+T 和原快捷键入口接通。

- 旧 HTML 模板转换为 Markdown 插入，标题与前文保留空行边界。发现并修复最初的标题粘连问题。
- 历史恢复可在旧富文本与 Markdown 之间切换；往日此时／拾光回顾共用编辑树正常挂载，返回来源功能继续工作。

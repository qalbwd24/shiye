## 当前可用流程

1. 在“云同步”中填写 WebDAV 根地址、用户名和密码，先点“测试连接”。
2. 手机数据已经导入电脑且云端为空时，点“合并并同步”，电脑库会作为第一份云端数据上传。
3. 云端已有数据时，程序先按稳定标识合并；发现冲突会停止上传，等“冲突管理”处理后再同步。
4. Android 端读取同一 `diary/diary.json` 以及 `diary/` 下媒体，因此手机和电脑使用同一份数据格式。

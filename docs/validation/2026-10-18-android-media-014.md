# Android 0.14：媒体对齐、简化图库与保留式安装

2026-10-18。正式包 `0.14.0-media/code16`，SHA-256 `29865bf46b6616f2eb4a37261e12398f9b6df8d997a8338abddcd3725b58a184`。主模拟器与荣耀 Magic7 均已 `install -r` 成功、版本回读并用标准 ADB 启动。手机从 0.11/code13 升级，模拟器从 0.13/code15 升级。没有卸载主包、清数据、导入模拟器资料或操作正式电脑日记。手机交还用户继续 UI 手测，不继续自动操作。

## 已交付

- 全部发送状态沿同一个原小飞机；空态/发送业务规则保留。表情入口改为单一缩略图库：去普通表情切页、大标题、帮助说明、大导入条和每图编辑文字；导入/排序/关闭使用小图标。
- 点缩略图直接发原件，真实本地保存 ACK 后关闭；保留文字草稿，引用写入发送消息。长按管理名称/备注/移除，复用共享收藏客户端；排序模式触摸拖动或用前移/后移，取消拖动恢复原顺序。
- 排序独立保存为本机 `view:sticker-panel-order:v1`，保留未知字段/暂未出现 ID，新收藏追加。后端没有排序写口，不往收藏 DTO 私加顺序，不宣称顺序已云同步。
- 原生固定收藏 API、原件上传及受保护 Range 下载，独立网络队列。默认离线，在“设置→服务连接”显式连接收藏服务。启用后合并本地与服务端收藏，记忆启用状态；错误保留原件和待重试修改。地址固定 scope，不能把另一库空目录当作删除。
- 完整服务端收藏 DTO 快照及未知字段保留；采用实际 ACK 的标准化 name/note/group/createdAt/updatedAt/deleted，同时保留本地 ID、Blob、预览和来源。迟到 ACK/旧目录不覆盖较新编辑，清空备注也按真实回执处理。
- 收藏名称/备注/别名的本地索引提供最多 5 个文字联想；约 150ms 延迟，输入法组词时隐藏，点选才发送，不把输入正文发到外部。实际已缓存原件才参与建议；不抢 Enter、不在每个按键遍历整库。
- 收藏表情按当前消息字号约 10 字等比显示，原图/窗口为上限；普通照片不统一缩小。首帧预览与原件身份分离，GIF 重发原字节。附件空说明 Enter、返回先关闭上层菜单/看图的既有路径保留。

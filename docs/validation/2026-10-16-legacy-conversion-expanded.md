## 范围与迭代

- 只 GET 正式本机 API，捕获 700 篇私有源快照和媒体登记表；排除隐藏/删除/草稿/演示与聊天归篇。本轮验证旧长篇，不把结果泛化为聊天撤回迁移已完成。
- 200 篇开发样本包含之前 35 篇记录的当前版本，另覆盖年份、HTML/Markdown、长短、附件、复杂结构及随机样本。500 篇未参与开发调整的随机样本单独保留，算法冻结后执行盲测。
- 先修复旧 Markdown 换行语义和段内时间识别；首次扩大样本又发现 blockquote 的块间 HTML 排版换行被误造为两空段。转换器和独立校验器各补回归，不放宽成忽略所有空白。真正空段、br、全角缩进继续保留。
- 开发/盲测报告存有算法文件 SHA-256，两批哈希一致；盲测后未为样本改动算法。运行器/预览状态的修正不改变转换规则。

2. 5 篇包含非图片附件：完整文件关联与顺序保留，前置描述可供下载查看；当前富文档 image 子集尚不能把这些全部变为原生媒体块，明确标为预览需核对。
3. 1 篇原始/当前编辑时间有分歧，回看兜底时钟保留未知并标记复核，没有隐式选择转换时刻。
4. 1 篇含未确定的时间写法；保留原表达和问题码，不冒充已识别完整时间。

# 2026-10-15 自定义表情映射与 F15

本轮更新独立聊天预览，正式拾页版本仍为 0.9.17。测试使用合成消息库，不触碰正式日记正文或微信数据。

## 使用入口

- 设置 → 输入与快捷命令 → 管理 emoji 与表情包映射：输入名字（如 `/开心`），选择 emoji 或已导入的本地表情包。名称允许中英文字、数字、下划线和短横线，忽略大小写与兼容字符形式；内置命令保留名称不能覆盖。
- 输入别名后 ↑↓ 选择、Enter 确认；emoji 替换该命令，表情包进入发送预览。输入途中不自动发送；中文组词期间不触发。
- 映射可改名、重新绑定和删除。删除素材时保留映射的失效提示，缺失素材不吞掉输入；历史已发送消息和附件不受映射修改影响。
- 默认全局 F15：聊天在前台时保存草稿并收起；在其他软件或后台时唤回并聚焦当前话题输入框，保留光标、未发送内容和默认中文设置。未选话题时打开最近已有话题。
- 普通关闭保存收起；设置 → 全局快捷键与后台可打开拾页统一热键设置（F13–F24、禁用），也可配置聊天收起确认。键位冲突回滚原键位。托盘可明确退出；完全退出后不接收按键，没有自动开机启动。
- 聊天窗口右上图钉切换原生置顶，状态立即保存；普通关闭、退出重开均恢复选择。
- 固定入口为项目根目录 `拾页聊天.exe`；开始菜单 → 拾页 → 拾页聊天。固定入口启动现有本地预览，重复打开唤回同一进程。

## 实现与存储

映射保存在独立资产 IndexedDB 的 `mapping:<规范化名称>` 项，改名与重名检查用同一读写事务，表情包通过稳定素材 ID 关联。异步读取素材后再次核对光标处命令，避免误删用户新输入。编辑器和图片／GIF 发送流程继续复用。

共享 `QuickHost` 使用 `RegisterHotKey` 与无重复修饰，分别按消息 ID 分发快捷记录与聊天。聊天宿主不注册热键、不再创建托盘，仅通过单实例 Mutex／命名事件接收打开、切换、退出意图。热键命令索引在 `public/shared/hotkeys.js` 的 `desktopWindowCommands`。收起前触发现有草稿保存动作，再等待本地 Worker 的写队列提交；保存失败保留窗口，不用隐藏代替成功。

# 2026-10-15 聊天布局、独立壁纸和输入修复

本轮仅更新拾页本地聊天预览及其窗口宿主。正式版仍为 0.9.17，正式日记和已发消息不批量改写。

## 操作

- 原聊天顶部横栏移除；左上独立按钮折叠／展开对话栏。输入框灰色提示为当前对话名。
- 深灰窗口框直接提供图钉、最小化、最大化／还原和保存后退托盘。标题处可拖动，边缘可调整大小。
- 设置 → 外观、中文输入、字体与时区 → 消息位置：靠右／靠左。消息与输入区收紧侧边留白。
- 新建或编辑对话时可选择壁纸，原图保存本机，同时用于该对话的头像。切换对话自动切背景；未选择的旧对话沿用旧默认背景。
- 输入框 ↑↓ 切换对话并保留各自草稿；Esc 打开对话选择，↑↓、Enter 选择，Esc 返回输入。不再通过 Esc 进入 Telegram 的 Chats/Channels/Apps 页面。中文组词、斜杠补全、弹窗与图片查看器优先接管按键。
- 设置 → 全局快捷键与后台：可开关“窗口靠近屏幕边缘时自动吸附”。使用显示器工作区，避免覆盖任务栏；保存最终位置，支持负坐标副屏。
- × 和 F15 保存后隐藏当前聊天窗口并保留 WebView，不销毁进程；F14/F15 继续由拾页统一后台接收。快捷记录继续按用户原有恢复时限保留页面；明确退出托盘才结束后台。

## 修复

新壁纸逻辑在启动时读取当前对话过早，导致 byTabId 尚未初始化时抛错；当前桥接对启动中状态返回空身份，初始化完成再更新背景。

Markdown 保留原文，在正文显示边界用项目已有的 Marked 18.0.13 解析 CommonMark/GFM；标题、列表、引用、分隔线、链接、表格、任务列表、删除线、围栏代码及 ==高亮== 扩展共用一条渲染路径。既有 Ctrl+B 等富文本实体同时保留，代码和代码实体中的符号不再被解析。原始 HTML 显示为文字，渲染结果经过标签与属性白名单重建，网络图片不自动获取。解析结果按文本和实体缓存。

仅纯 emoji 消息使用统一大尺寸，混排保持行内大小；覆盖旧消息读取与实际发送。字体使用系统彩色 emoji，解除原上游按 emoji 个数设置的文字宽度限制，避免裁切。

聊天时间分隔默认按相邻消息的 30 分钟空闲间隔判断，跨天自动分隔。设置 → 消息与图片可调 1–1440 分钟；与话题归篇间隔分别保存。默认北京时间，设置 → 外观、中文输入、字体与时区可改为跟随系统。所有消息保存的 UTC 时间戳保持原值。

边框图钉与最大化操作后将焦点送回输入框，避免空格停在按钮上变成再次点击；空格还须通过实际键盘输入验收。

## 存储与兼容

独立消息库的 shiyeRooms 增加可选 wallpaperAssetId，资产库保存 wallpaper:room:<UUID> 的 Blob。编辑元信息合并旧字段，图片更换不删除原资产或旧消息媒体。messageAlign 属于本机外观，EdgeSnap 属于窗口本机设置。正式日记格式不变。

## Markdown 语法范围

`**加粗**`、`__加粗__`、`*斜体*`、`_斜体_`、`==高亮==`、`~~删除~~`。围栏代码使用三个反引号；三个单引号是普通文字。CommonMark/GFM 不包含数学公式和 Mermaid，当前不宣称这两类扩展已实现。此轮统一的是聊天预览显示，正式长篇日记的现有编辑器保持原实现。

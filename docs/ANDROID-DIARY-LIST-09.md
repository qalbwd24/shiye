# Android 思绪列表 0.9 UI 小阶段

2026-10-18。用户确认手机优先快速写、看，复杂统计与管理留在电脑。参考用户提供的思绪列表截图，只取紧凑日期栏、全文宽摘要、每条底部灰色元信息和细分隔线，不复制截图正文或私人壁纸。修改范围仅 `DiaryListPage.java`；不改正文、长文切分、存储/同步算法，不操作设备、部署或版本。

## 已实现

- 顶部去掉冗余“思绪”标题，为日期/日历、搜索图标、右侧设置。用户已确认点击搜索才展开文字/日期输入；再次点击收起，保留当前查询。日期可输入 `YYYY-MM-DD`，可用日历选择或清除；关键词与日期共同筛选，分类横滑继续保留。分类增删改排序通过既有设置入口管理。
- 日期筛选只从已有 `date` 读取前10位并验证，不改原值、不转换日期所属时区；空/坏日期归“日期未定”，不补成今天。默认顶部显示今天作为日历入口，不代表空日期记录被补写或默认限制今日。
- 常驻刷新按钮已移除，列表顶端下拉至提示“松开刷新”后刷新；未满屏及空列表也可下拉。刷新中/完成/失败仅短暂显示状态，失败保留原列表。原自动刷新策略继续兼容。
- 根代理只读 review 指出的两项 UI 风险已最小修复：输入变更前按当前实际显示的查询 key 保存稳定条目 ID/offset，过滤后统一恢复该 key 的锚点；无锚点或条目不在结果中则回到首项。快速输入使用 query/filter 版本与 key 校验，旧延迟任务不能恢复到新查询。日历设置日期会取消 TextWatcher 排队任务，仅过滤一次。刷新状态改为列表顶部 overlay，出现/消失不再占28dp布局槽，不改变列表几何。
- 按用户新增“切回先本地立即显示，后台静默刷新”要求，列表根视图保存为 `final LinearLayout page`，新增 `public attach()` 复挂同一个 View/ListView；查询和分类未变时不重筛、不重设滚动、不发请求。明确查询/分类 key 变化时才同步输入、分类选中外观并沿同一锚点逻辑过滤。`public compatibleCatalog()` 比对分类 fingerprint；分类新增/删除/改名/排序改变由宿主重建。宿主先设 `h.diaryListPage=this` 再 `attach()`，随后单独调用一次 `refresh(false)`；本类 attach 不抓 bootstrap，避免重复请求。MainActivity 的缓存/静默刷新调度由根代理实现，本文件不另建缓存数据模型。
- 主体为白浅色全文宽摘要流，移除旧左侧大日号。已有标题独立显示；无标题时摘要优先，不重复“未命名日记”。摘要最多4行，只用已有 `preview`；底部一行显示可用日期、星期、时间、分类、首个标签和显式地点字符串，过长省略。仅 `date` 自身有时分时显示其时分；只有创建时间的条目标明“创建 HH:mm”，不冒充事件时间。地点无数据则不显示，不推断地址或读取设备定位。
- 顶部轻量连续记录天数按现有有效日期去重，计算包含今天或昨天且未中断的当前连续记录；过去已断开的历史连续段不冒充当前连续记录。篇数按当前筛选结果显示，不增统计工作台。
- `entry.pinned` 为现有电脑版 Entry 标记的 UI 接入，置顶条目以浅蓝更深背景与“置顶”组显示，稳定排在前面，组内沿用 Repository 日期顺序。长按支持置顶/取消置顶，调用 `setEntryPinned {id,baseRevision,pinned}`，正常保存后刷新；冲突/失败显示原错误并重读，不用旧 revision 覆盖新数据。该 LocalStore 薄适配由独立代理负责，本文件不增存储字段或写第二模型。

## 未加入与后续

当前 bootstrap 摘要没有已有的媒体缩略图/地点摘要通用契约，所以不为列表扫描或解析正文、另造媒体算法；已有显式地点字符串能展示，无字段不伪造。图片摘要缩略图等后续接电脑已有 metadata 时再增加。用户提到未来便签互通仅记录在此，不建立便签第二套数据模型。顶部自选壁纸未来适配，本阶段浅蓝横幅，不额外引入图片解码。

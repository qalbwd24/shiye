# 0.9.11 快捷输入改进

日期：2026-10-15。基础输入/窗口代码已修改；发布与运行版本核对见 [验收记录](validation/0.9.11-validation.md)。非线性分块仍暂缓，AI 对话/标题调用、跨软件 AI 读写与用户插件系统未纳入本轮代码，不以设置或文档存在冒充接入完成。

## 使用入口

- 顶部“上一篇／下一篇”按成功的快捷编辑历史双向切换；到最新篇按“下一篇”，在同一窗口打开新开窗口使用的选择弹窗。取消保留当前篇，选分类后准备新草稿；仍默认选中首项“上一篇”，可以恢复最近一篇。切换前保存失败时不离开。

- 快捷窗口首次打开，“上一篇”在列表最上方并默认高亮；↑/↓ 切换，Enter 执行。历史仍在读取时按一次 Enter，加载完成会继续打开；找不到记录时保留选择页，让用户选择分类。
- 设置 → 分类与标签 → 调整分类顺序。使用固定操作区上移、下移、最前、最后或指定序号；可以连续操作、搜索定位、取消或一次保存。搜索序号指完整列表。其他窗口改动顺序后旧预览保存返回冲突，不静默覆盖。
- 设置 → 编辑与记录 → 快捷窗口进入编辑时：先写正文 / 先写标题。标题 Enter 或末尾 ↓ 进入正文；正文折叠光标在开头（含默认缩进）时 ↑ 回到标题末尾。退格不接管。HTML 和 Markdown 分别检查边界，中文组词及选区优先。
- 原生快捷窗顶部“热键与输入”，或托盘图标右键同名菜单：下拉选择 F13–F24，按需加 Ctrl/Alt/Shift；可禁用关闭确认、选择默认输入模式。默认无按键绑定，用户自行配置 Caps/Hotkey，未自动开启开机启动。
- 热键在外部软件中按下，唤回最近操作窗口并恢复标题/正文焦点；在快捷窗内按下，确认后通过原有保存握手关闭当前窗。关闭全部快捷窗仍保留托盘宿主；托盘菜单“退出快捷记录托盘”才退出宿主，不强制终止日记服务。
- 默认中文策略在每次唤回后请求已有中文输入法，不模拟全局 Shift，不锁住英文；同一次停留内切换标题/正文不再请求。输入法不响应时底部显示未确认切换，可手动切或选择跟随系统。实际中文候选状态依输入法验证，不能只看请求发送成功。
- 原生快捷窗 Ctrl+滚轮、Ctrl++、Ctrl+- 缩放，Ctrl+0 回到 100%，比例范围 50%–250%。比例独立于正文样式/字体和系统 DPI；其他已开窗口不跟着改变，后来新窗读取最近比例。

命令行默认运行仍多开，并增加 `--toggle`（切换/关闭）、`--resident`（仅驻留）、`--exit-host`（请求安全退出宿主）。入口用同一项目/本机服务/状态目录身份连接托盘宿主。隔离验收必须同时传 `--url` 和 `--state-dir`；`--bridge-test`/`--host-test` 只允许隔离环境。

## 修复和回归

- 正文紧贴 `---` 时，Markdown 会把前文识别为 Setext 标题，呈现变大/下划线感。现在完成该行并回车，会先插入必要空行再创建分割线，自动缩进关闭也适用。旧篇加载保持原语法；已有标题不因打开而转换。工具栏分割线改为在选区末尾插入，防止误把所选前文替换成横线。

- 自动缩进的全角空格行不等于 Markdown 空行：完成分割线时补入真正空行，避免空 Setext 标题；只作用本次用户输入，不扫描改写旧篇。
- 启动很快按 Enter 不再丢弃打开上一篇的意图；期间改选分类/搜索会取消待执行意图。
- 日期字符串 `YYYY-MM-DD` 作为民用日期处理，不经 UTC 解析再取本地日期，修复 UTC 以西时区连续天数统计。
- 先标题保存、继续写正文、草稿转正式 ID、关闭失败保留窗口、同篇冲突及图片附件关联为回归重点。已有独立壁纸/字体、滚动留白和媒体上传队列继续保留，没有重写媒体压缩或日记数据结构。

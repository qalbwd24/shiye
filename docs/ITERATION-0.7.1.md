# 0.7.1 工作区与阅读交接

## 本轮结果与设计方向

本轮把工作区固定在窗口内，让日记列表、正文、图评栏各自滚动，减少阅读长文和评论时整页位移。右栏的图片与评论共用一个滚动区域，顶部操作和底部内容都应可达。图片阅读采用无外围框的自然比例单图，保留图上左右箭头、计数和圆点，支持横向拖动；正文下方提供附件缩略图和排序手柄。

页面边缘固定保留活页本式标签：导航、列表在左侧，图评在右侧。配色沿用应用主题，默认青绿浅色，不照搬参考图的配色；悬停轻亮、文字微抬，按下提供反馈。切图过渡为 190ms，工作区开合为 220ms，并尊重系统减少动态效果设置。就地编辑时同样可拖动正文与图评之间的分隔条，松手后保存宽度。

“全部日记”与各分类合并为“日记分类”组，点击一个项目即展开对应列表。现有日期、媒体和心情筛选仍会参与结果过滤。

用户偏好由根 agent 统筹设计和集成，子 agent 按模块实现与核对；最终页面效果、测试及正式升级由根 agent 统一验收。该版本不修改后端日记、媒体或加密备份格式。

以下为根 agent 在文档交接时提供的阶段性结果，最终以 [验收目录](validation/) 中本轮记录为准：

## 追加：拾光回顾与往日此时

用户后续要求增强随机回顾，并把回顾内容统一为完整阅读页。新增 `public/features/recollection.js` 与 `public/styles/recollection.css`，两种回顾共用单篇／列表模式选择器。单篇由根入口挂载唯一现有阅读器，不复制编辑器、图库或评论 DOM；模块内切篇、改范围、切模式都先等待正文保存。异步操作要核验当前容器仍连接，根入口也需在异步选择后核验挂载代次，避免切视图后抢回阅读器。

随机默认 Fisher–Yates 一轮不重复；轮间通过调整首项避开刚看过的一篇。随手一页允许再次抽中旧篇，但范围多于一篇时避开相邻重复。当前浏览器的 `shiye.recollection.v1` 保存范围、模式、轮次及 ID：一轮最多 5000 个 ID，前后浏览历史最多 200 个 ID；超大轮只在页面内维持，刷新重新开始。每次渲染按实时库检查隐藏、删除、草稿和范围，不缓存真实正文、标题或评论。往日此时复用 `shared/recall.js` 的周期与闰日规则。

原版证据为研究目录 `research/2026-09-10/android/sources/com/chenupt/day/memory/RandomActivity.java`：103–109 行读取 `random_filter`、排除隐藏及分类之外的日记，使用 `new Random().nextInt(arrayList.size() + 1)` 随机插入；154 行保存分类筛选；373 行进入列表活动。269 行明确标注 onCreate 反编译不完整。本版沿用可读的分类、隐藏排除与随机顺序思路，Fisher–Yates 及避免轮间紧邻重复为本版实现，不声称原 Android 分布、全部活动或界面逐行复刻。

阅读器明确返回 false 且回顾容器仍有效时，模块重新检查实时资格并重绘；已离开的视图不重试。缺省 undefined 返回保持兼容，不触发循环重试。

模块级检查：`tests/recollection.test.mjs` 与 `tests/insights.test.mjs` 合计 13 项通过，限定文件 ESLint 与 Prettier 检查完成。它们不替代根 agent 的完整装配、实际阅读器浏览器验收及最终升级记录。

## 最终交互：就地编辑与相册

本节覆盖本轮前期“阅读／专业写作”两套状态的描述。最终采用 `#editorPanel.inline-editing` 就地编辑：点击正文或标题显示工具，保留侧栏位置与宽度，不自动折叠；正文下方 `#attachmentEditor` 展示可操作的附件缩略图，右侧图库对同一篇日记在编辑期间保持原有展示。点击“完成编辑”先等待 `flush()` 成功，再解除编辑状态并同步右侧最新附件。正文和附件仍然自动保存，这次确认是展示同步，不能解释为延迟写库、整体事务或取消回滚。

相册独立为 `public/features/album.js` 和 `public/styles/album.css`，支持自然比例瀑布流、整齐方格与列表、舒适／紧凑密度、日记日期或媒体名称排序以及媒体类型筛选。按媒体 ID 合并可见来源，保留关联日记入口，排除隐藏／草稿／回收站；每批最多 80 项，避免一次建立全部卡片。`shiye.album.v1` 只保存当前浏览器的显示偏好。测试入口为 `tests/album.test.mjs`，实际视觉与滚动由根 agent 复核。

拾光回顾与往日此时的单篇复用 `features/entry-reader.js` 管理的唯一阅读器；列表与单篇切换不会复制正文或评论实例。页边活页标签仍沿用主题青绿浅色和轻微 hover／按压反馈，“全部日记”与分类共属“日记分类”。这些新增及最终调整发生在前述 70 项测试阶段之后，最终全量测试、实际界面与正式升级状态仍以根 agent 的 validation 记录为准。

回顾翻篇或切换显示方式在保存成功后先将旧阅读器／列表淡出约 100 ms，再挂载新页并淡入 200 ms；系统减少动态效果时跳过动画。动画期间暂停重复操作，离开视图或取消动画后检查容器代次，不抢回 DOM。两种回顾的列表每批 80 篇，提供“再显示”与已显示／总数，追加时保留原有卡片和滚动位置；实时资格变化时重新核对内容。新增测试覆盖动画次序／取消／减少动态效果与 161 篇分批全部可达。

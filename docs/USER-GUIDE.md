## 组件与 AI 数据

在“设置 → 组件与 AI 数据”查看本机接口地址、打开日记卡片示例，或点击“导出结构化 JSON”。导出可选择当前日记、当前列表、全部非隐藏日记；评论默认关闭。JSON 是可供分析的明文结构，包含正文源文、分类标签、时间与附件信息，媒体本身仍在本地；完整保存仍使用备份。没有自动接入或发送给外部 AI。日记与壁纸、日程组件保持各自独立，接入方法见 [组件与 AI 数据接入](OPEN-DATA.md)。

## 快捷窗口设置与按键

需要新选篇目时，快捷窗口显示“上一篇／分类”选择页：最上方默认选中“上一篇”，打开最近有内容、未删除的快捷记录，不把它当成分类；无历史时提示选择分类。上下方向键切换，Enter 执行。进入正文后，顶部“上一篇”继续逐篇向前。0.9.14 时限内恢复已有后台窗时跳过此选择页。

标题编辑完成后按普通 Enter，只把光标送回正文，不自动插入时间。中文输入法组词时的 Enter 优先确认候选；下一次独立 Enter 才进入正文。

Alt＋T 在句子中间只插入 `[年月日  时:分:秒]`，不换行、不移动段落。段末按下时，上段和时间行之间空一行，时间与下一行默认各缩进两格，光标停在最后的缩进后：

```text
　　上一段内容

　　[2026/09/30  12:34:56]
　　从这里继续写
```

空白行会复用，不重复叠加缩进；关闭自动缩进后不加两格。代码、列表、引用、标题等结构内仍为就地插入，避免破坏格式。选中文字时只替换选中的文字。

Markdown 正文独立行输入 `---` 后回车，会显示分割线；默认两格缩进会自动处理。点击线条可回到标记编辑。未缩进的 `---` 若紧接上一行文字，中间没有空行，按标准 Markdown 解释为二级标题；需要分割线时先空一行。旧富文本日记没有自动改为 Markdown。

批量媒体仍可先勾选“保留原件”，默认压缩。全部上传、处理并保存到日记后，队列自动收起，不用点叉；失败项会保留错误和重试按钮。可从主页面“上传队列”重新查看处理结果。

## 大文件导入与压缩加密备份

“备份与导入”→“旧版备份与原格式导入”→打开旧格式备份，可导入 Android ZIP、Windows 加密备份、WebDAV JSON。原件、原始 JSON 和未知字段保留；Markdown 转富文本；分类、标签、媒体关联和隐藏状态导入。日记日期使用原 `createTime`，实际创建时间使用 `recordTime`。复杂自定义排版和内联媒体位置仍需逐例核对。

导入现采用磁盘暂存和流式 ZIP 解压，支持 ZIP64、Store 和 Deflate，检查 CRC32 和 SHA-256；单包及展开总量目前各限制 64 GiB、100000 个成员，单个日记元数据文件限制 64 MiB。外层另设 ZIP 密码或分卷 ZIP 需要先合并／解开外层。非 ZIP 元数据限制 128 MiB；单个新增媒体限制 16 GiB。这些是保护上限，不表示已用 64 GiB 样本验收。

新版入口“完整备份”生成 `.syvault2`：按 2 MiB 媒体块读取，每条记录先 gzip 压缩，再 AES-256-GCM 加密，写入本地文件。大附件不整包读入内存；元数据仍整体加载，因此不是无限容量数据库。密码仅在本机浏览器使用，至少 12 个字符，不保存到服务器。PBKDF2-SHA256 600000 次、随机 16 字节盐，每块随机 IV；格式头与块顺序参与认证，结尾记录必须完整。恢复先校验全部文件 SHA-256，再追加到当前库。原有日记不覆盖；快捷键／偏好不覆盖当前设置。

完整备份包含原始 ZIP 与已解出的媒体两份来源内容；音视频本就压缩，文本封装也有开销，所以新文件可能比原 ZIP 大。首次大备份及校验需要时间，请保持应用和服务运行。暂不支持关闭页面后继续任务、断点续传或增量备份；异常退出可能留下暂存文件，不应把 `.partial` 当完整备份。磁盘需同时容纳当前库、导入／恢复暂存及新备份，建议留出预计新增数据量的 2–3 倍空闲空间。

旧 `.syvault` 保留兼容入口，仅适合媒体与原件总量不超过 128 MiB 的旧整包格式；大库请使用新版 `.syvault2`。

本地工作库和媒体为明文。本地锁限制应用及接口访问，**不等于磁盘加密**。兼容手机的 WebDAV 同步也保存普通 `diary.json` 与媒体，HTTPS 只保护传输，不能代替端到端加密；需要服务器无法看到正文时，请使用 `.syvault2` 加密备份或等待后续加密容器。同步入口会要求你明确勾选风险确认。

## 拾光回顾与往日此时（0.7.1 追加）

打开“拾光回顾”或“往日此时”，默认进入单篇阅读，直接查看原有完整正文、图片和评论；右上可切换“列表”，从卡片打开日记。两处共用阅读方式偏好，当前浏览器会记住。列表每批显示 80 篇，底部“再显示”可继续查看余下全部结果。切篇时先保存，再短暂淡出、淡入；开启系统减少动态效果会跳过动画。

拾光回顾默认“不重复漫游”：范围内每篇随机排入一轮，整轮看完后可开始下一轮；多于一篇时，新一轮不以刚看过的日记开头。“上一篇”回看已抽过的记录，“下一篇”先沿浏览历史前进，再抽新篇。“重新开始”重新洗牌。“随手一页”每次独立选择，但多于一篇时避开紧邻重复，其他篇可以再次出现。

展开“范围”可选分类、开始／结束日期，或排除最近 7 天。往日此时则选择目标日期与每月、三个月、半年或每年的周期，同一日号且间隔为周期整数倍的过去日记才会出现；闰日只匹配真实存在的 2 月 29 日。两种回顾均排除隐藏、草稿和回收站。

偏好与浏览顺序只保存在当前浏览器，记录 ID、位置与范围，不缓存正文或评论。最多记住 200 次前后浏览记录；一轮最多 5000 个 ID 可在刷新后继续，超过此数量的轮次只在当前页面内维持，刷新会重新生成。删除、隐藏或改分类后会重新检查资格，不继续展示已经不符合范围的旧记录。切篇前会先保存当前正文，保存失败时保留当前页并提示。

## 相册（0.7.1）

“相册”可选择自然比例瀑布流、整齐方格或列表，并切换舒适／紧凑密度。按日记日期从新到旧、从旧到新或媒体名称排序，可只看图片、视频或音频。相同媒体只显示一张卡片，卡片保留各篇关联日记的入口；点击媒体或日记入口进入原日记查看。隐藏、草稿和回收站中的日记不进入相册来源。

相册按批显示，每次最多追加 80 项，底部说明已显示数量；更改显示方式不会删改媒体。排列、密度、排序和类型仅记在当前浏览器，清理网站数据后回到默认设置。

## 0.7.2 输入与随机相册

新建空白正文默认空两个全角格；普通 Enter 换段后也自动空两格，Shift+Enter 只软换行。设置→编辑与记录→正文开头与普通换段自动空两格可关闭。模板和已有正文保持原样，列表、标题、引用、代码、表格内继续使用其原换行语义。

Alt+T 在正文插入本机日期时间，如 [2026/09/14 23:15:11]。日期与时间间有两个半角空格。搜索、标题和评论不会触发；可在快捷键设置中改绑。系统 CapsLock 脚本由你自己配置，本轮未修改。

相册→排序→随机排列，点击“重新打乱相册”获得新顺序；筛选、加载更多和刷新保持本轮顺序。日记列表中含图片的记录使用第一张图片作为淡色背景，不改变图片文件。

## 从浏览页返回（0.7.6）

从拾光回顾、往日此时、相册、地点等页面点击“打开日记”，顶部左侧会显示“← 返回拾光回顾”等来源名称；日历点击日期后显示“← 返回日历”。点击即可回到刚才的页面，恢复范围、阅读方式、随机顺序、已加载数量和滚动位置；日历保留原月份。

返回前会先保存正文；保存失败会提示错误并保留当前页，可稍后重试。返回的是最新内容，不会用旧浏览快照覆盖刚编辑的日记。主动点击其他导航、分类、搜索或新建日记，会结束这次返回路径。此入口仅保留当前打开过程，刷新或关闭窗口后不恢复，也不改变浏览器后退键。

## Markdown 实时编辑（0.8）

新日记默认使用 Markdown；已导入且保存有匹配 Markdown 源码的日记也使用新编辑器。输入 `# 标题`、`**粗体**`、列表、引用、任务框、代码和链接即可就地显示；光标所在行显示语法，移开后隐藏标记。正文上方“显示源码／实时预览”切换仅改变显示，在当前浏览器记忆，保留选区与撤销记录。

普通段落回车按原设置空两格，列表、引用、代码等使用 Markdown 的续行逻辑。Tab 空两格、Alt+T 插入日期时间、可自定义快捷键、撤销重做、模板与自动保存继续可用；链接使用 Ctrl／Command＋单击打开。

旧 HTML 日记继续按原富文本显示和编辑，不会因打开或更新版本而自动转换。点击“转为 Markdown”，核对源码和“查看效果”后采用新编辑器；取消不写入。首次转换的原 HTML 独立保存，可点“转换前原文”查看，也随加密备份保留。恢复历史会恢复当时的正文格式。

媒体仍使用原上传队列、压缩与附件区；新增媒体可粘贴、拖入或通过右侧添加。点击“插入附件图片”把本篇图片引用插到正文，引用使用稳定媒体 ID，图片不复制第二份。编辑中的右侧图片展示仍在完成编辑后同步。转换后的单行下划线、文字颜色保留；表格、多行复杂 HTML 目前保留源码编辑，HTML 导出保留渲染效果。

本版本没有加载 Obsidian 社区插件；已预留可信代码扩展接口。公式、双链、可视化表格编辑、第三方插件管理属于后续功能，不等于已兼容 Obsidian 插件。

## 简洁工具与常用语法（0.8.1）

继续直接用 Markdown 记日记。正文上方仅保留“编辑工具”，点击展开格式、日期、模板、分隔线和源码切换；折叠状态会在当前浏览器记住。旧富文本的“转为 Markdown”和“转换前原文”也收在这里。自动保存状态仍在顶部显示。

普通段落后回车，即使带着自动空两格，单独输入 `---`、`***` 或 `___` 再按 Enter，也能生成分隔线；也可用工具里的“分隔线”在光标处插入。带自动空两格的 `# 标题`、`- 列表`、`> 引用` 和代码围栏同样在 Enter 时识别结构。普通中文段落仍按设置自动缩进。已有合法的“文字紧跟下一行 ---”仍遵循 Markdown 的二级标题语义。

Alt+T 显示日期时间 `[2026/09/22  12:34:56]`，Markdown 源码保存为 `\[2026/09/22  12:34:56\]`；不用自己输入反斜杠。日期不再显示成链接，原有未转义时间也按普通文字显示。手动输入 `\*`、`\#`、`\[` 等可显示字符本身；光标所在行保留源码，移开后隐藏转义反斜杠。代码中的示例保持原样。

### 快捷窗口 0.9.5

顶部“外观”可单独设置壁纸来源、透明度、位置、模糊，以及正文和标题的字体大小、粗细与行距；默认跟随主页面，保存后记住。再次运行“拾页快捷记录.exe”会打开新窗口；“新一篇”留在当前窗口。“上一篇”首击直接加载快捷编辑历史。正文未写满时也可向下滚动，底部留白不会存成空行。切回主页面后，离开正在编辑的正文/标题区域即可安全刷新其他窗口的保存结果。

详见 [快捷窗口 0.9.5 交接](QUICK-CAPTURE-0.9.5.md)。

# 深浅色（0.9.6）

快捷窗顶部“外观 → 深浅色”可选跟随主页面、跟随系统、浅色或深色，保存后记住。选择“跟随系统”时，Windows 应用颜色变化会即时更新，无需重开窗口；该选择与独立壁纸、字体互不影响。主页面在“本地功能设置 → 主题”选择“跟随系统”。没有旧主题设置时默认跟随系统，已有的浅色或深色选择不会被升级覆盖。

# 拾页 · 本地桌面日记

2026-09-14，版本 0.3.0。独立的本地应用，兼容已分析的一本日记备份，不是官方客户端。

## 启动与目录

双击 `F:\我的奋斗\启动拾页日记.lnk`，或本目录的 `拾页日记.exe`。

代码和运行库统一位于 `F:\我的奋斗\日记软件本地化\电脑前端`。启动器用本机 Node.js 启动仅监听 `127.0.0.1:18765` 的服务，并打开 Edge 应用窗口。无需 npm 安装，不能只移动 exe。关窗口后服务仍在运行，再次启动复用。命令行可运行 `node server.mjs`。

- `data/diary.json`：日记、分类、标签、历史、模板和设置。
- `data/media`：媒体文件。
- `data/originals`：逐字节保留的旧格式加密备份。
- `data/backups`：新建的 `.syvault2` 加密备份。
- `data/*-staging`：导入／恢复的临时工作空间。

浏览器缓存不是日记库；清理缓存不会删除上述数据。共享 Node.js 运行时仍在 D 盘。

## 大文件导入与压缩加密备份

“备份与导入”→“旧版备份与原格式导入”→打开旧格式备份，可导入 Android ZIP、Windows 加密备份、WebDAV JSON。原件、原始 JSON 和未知字段保留；Markdown 转富文本；分类、标签、媒体关联和隐藏状态导入。日记日期使用原 `createTime`，实际创建时间使用 `recordTime`。复杂自定义排版和内联媒体位置仍需逐例核对。

导入现采用磁盘暂存和流式 ZIP 解压，支持 ZIP64、Store 和 Deflate，检查 CRC32 和 SHA-256；单包及展开总量目前各限制 64 GiB、100000 个成员，单个日记元数据文件限制 64 MiB。外层另设 ZIP 密码或分卷 ZIP 需要先合并／解开外层。非 ZIP 元数据限制 128 MiB；单个新增媒体限制 16 GiB。这些是保护上限，不表示已用 64 GiB 样本验收。

新版入口“完整备份”生成 `.syvault2`：按 2 MiB 媒体块读取，每条记录先 gzip 压缩，再 AES-256-GCM 加密，写入本地文件。大附件不整包读入内存；元数据仍整体加载，因此不是无限容量数据库。密码仅在本机浏览器使用，至少 12 个字符，不保存到服务器。PBKDF2-SHA256 600000 次、随机 16 字节盐，每块随机 IV；格式头与块顺序参与认证，结尾记录必须完整。恢复先校验全部文件 SHA-256，再追加到当前库。原有日记不覆盖；快捷键／偏好不覆盖当前设置。

完整备份包含原始 ZIP 与已解出的媒体两份来源内容；音视频本就压缩，文本封装也有开销，所以新文件可能比原 ZIP 大。首次大备份及校验需要时间，请保持应用和服务运行。暂不支持关闭页面后继续任务、断点续传或增量备份；异常退出可能留下暂存文件，不应把 `.partial` 当完整备份。磁盘需同时容纳当前库、导入／恢复暂存及新备份，建议留出预计新增数据量的 2–3 倍空闲空间。

旧 `.syvault` 保留兼容入口，仅适合媒体与原件总量不超过 128 MiB 的旧整包格式；大库请使用新版 `.syvault2`。

本地工作库和媒体为明文。本地锁限制应用及接口访问，**不等于磁盘加密**。要交给网盘或自己的云服务器保存，请上传加密备份。新加密层不能直接被原版一本日记读取，但原来的加密原件仍在包内。官方账号和双向云同步尚未接入，不应直接公开此本地服务。

## 自定义背景与快捷操作（0.5）

左下角“外观与背景”可选浅色、深色或跟随系统，点色块或颜色选择器调整主题色。选择背景区域并上传图片，再调不透明度、填充与位置。整体、左侧、列表、正文、顶部可用不同图片；保存后重开仍保留。取消、关闭或 Esc 撤销未保存预览；恢复默认也需要保存才提交。

右击分类／标签可新建、筛选、重命名／合并、移除，或直接在该项目下新建日记。右击日记卡片可改标题、分类和标签、置顶、复制、导出、移入回收站；回收站右键可以恢复。也可以聚焦卡片后按 Shift+F10，方向键选择、Enter 执行、Esc 关闭。

点“我的分类”“常用标签”折叠或展开；点列表左上角箭头收起日记列表，再点箭头恢复。折叠状态保存在本机库。很窄的窗口仍使用原有列表／正文切换，不显示桌面收窄按钮。

完整加密备份会保存背景文件。恢复时勾选“同时恢复备份中的主题、背景和折叠设置”才替换本机外观；不勾选则保留当前设置。移除背景仅解除使用关系，不删除原始文件。

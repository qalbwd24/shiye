## 本轮实现安排

时间戳复用 `editor-input.formatLocalDateTime` / rich-body-adapter / date-time-edit的实际规则，格式 `[YYYY/MM/DD  HH:mm:ss]`，日期与时间之间两空格。本轮明确使用共享DEFAULT_TIME_ZONE北京时间，页面说明与电脑默认一致；未来真实库自定义时区由Repository接入，未声称已同步。图片底部缩略图附件区由canonical richdoc媒体派生；旧节点原位/原序保留，编辑时用小锚点表示，阅读不再铺大图，新图在canonical尾部追加、使用独立UTC insertedAt，不覆盖选区。桌面/媒体契约与当前段内图能力边界见[契约核对](ANDROID-SKY-CONTRACT.md)。

本轮外观基础：日记天蓝渐变、黑字、蓝色控件；思绪独立外观提供基础壁纸选择/移除、透明度/填充/位置与模糊，参考电脑偏好但不声称已跨端同步。壁纸不成为日记附件，不参与正文版本或时间索引。聊天继续成熟Web A界面和原独立壁纸边界，颜色统一浅蓝黑字。

分工：主代理原生导航/列表/壁纸存储桥及统一构建；diary代理三编辑资源；chat代理适配CSS及新目录资产；contract代理只读核对桌面时间戳/后端契约。公共编辑核、vendor、后端和桌面运行版保留。手机继续用户手测0.3.0，本轮先电脑AVD交付，不自动再次覆盖手机。

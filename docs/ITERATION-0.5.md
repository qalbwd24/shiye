## 第四版问题与修正

- 右键菜单点击时先 hide 清空 target，再传给 run，所有操作都可能拿到空目标；新菜单先捕获动作再关闭。
- 第四版用 markDirty 标记已删除日记，而该函数会忽略 deleted，导致移入回收站不能保存；新操作统一执行带 revision 的完整 PUT。
- 背景 UUID 文件没有扩展名，读取却用扩展名判断 MIME；新版识别文件签名并保存实际 MIME，通过受保护的 media 接口读取。
- 第四版 backgrounds 文件夹没有接入加密备份；新版背景属于 media，purpose=background，既不插入正文，也不加入相册／日记统计。
- 第四版上传就保存全部外观、取消无回退；新版只保存草稿引用，取消／Esc／关闭回到已保存偏好。未引用上传文件保留，避免误删。
- 折叠使用真正的按钮和 aria-expanded，支持键盘，展开按钮始终留在折叠内容外。右键菜单支持方向键、Home/End、Esc、Shift+F10。
- 修正新增独立空标签无法保留的问题；分类变更同时维护模板绑定和回忆分类筛选。

## 数据与兼容

schema 仍为 1，加密头、算法和分块格式不变。旧日记、未知原字段和原件继续保留。首次启动扫描第四版被引用的背景：复制到 media、登记元数据并重映射偏好，保留旧文件；再次启动不重复导入。不存在或不识别的旧图片保留引用，界面可以重新选图。

完整 .syvault2 备份包括背景文件、主题和折叠偏好。恢复默认只追加日记及媒体，保留本机设置；用户勾选“同时恢复主题、背景和折叠设置”后才应用备份外观，并重映射图片 ID。独立标签也纳入恢复。旧 .syvault 读取继续保留；它的旧设置恢复规则不变。

# 拾页产品名称

2026-10-17 用户确认，“拾页”为总项目，二级项目名称如下。

| 名称 | 对应功能         | 窗口标题    |
| ---- | ---------------- | ----------- |
| 主页 | 主界面、日记管理 | 拾页 · 主页 |
| 思绪 | 原快捷写作窗口   | 拾页 · 思绪 |
| 随想 | 聊天式窗口       | 拾页 · 随想 |
| 便签 | 多标签便签       | 拾页 · 便签 |

功能解释可保留“快捷写作”“聊天”等普通描述；入口、窗口与设置标题使用上述产品名。随想作为常驻入口，在标题栏左侧提供“思绪”“便签”，窄窗缩为固定尺寸图标并保留提示。

本次不重命名EXE、目录、接口、存储字段和用户自己的会话，不更改快捷键绑定，不迁移数据。思绪对应已有快捷写作能力，名称调整不引入新的协作功能。

所有开发会话应积极维护此表及相关需求、实现、验收和实际运行状态，新增入口也遵循此命名。实施与运行证据见 [命名验收](validation/2026-10-17-workspace-visible-names.md)；聊天功能逐项见 [U32–U40](CHAT-UI-OPTIMIZATION-2026-10-16.md)。

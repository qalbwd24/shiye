## 打开

在 `D:\拾页` 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/start-notes-preview.ps1
```

此入口确认或启动独立静态服务，再打开 `outputs/notes-ui/app/拾页便签.exe`。服务已启动时，也可直接打开该 EXE。首次构建用同一命令加 `-Build`；有便签窗口正在编辑时先正常保存关闭，不覆盖运行中的程序。

## 写与切换

当前界面已精简为标签、标题、正文和轻量状态栏，格式工具点右侧“格式”展开；成功保存只显示小勾。原型数据范围说明在设置中，不占正文页面。

Markdown 现在采用实时预览：当前编辑段落保留 `# 标题`、`**加粗**`、`*斜体*`、反引号行内代码等标记，按 Enter 换段或移开后显示格式；再点回去可直接修改标记。撤销/重做、切标签和重开继续保留源码。代码与转义内容不误当排版，图片仍沿用原有图文节点；这是基础文字块预览，尚不是完整的Obsidian源码模式。

- 直接点大标题命名；这是独立文件标题（常规26px、窄窗24px），不属于正文 H1～H6、不进入目录。标题里 Enter/向下进入正文；F2 仅在设置启用标签快捷键后使用。
- 点“待办”后输入事项，Enter 继续下一项；勾选完成，底部显示完成数量。正文按去空白后的字符数统计，标题不计入。
- 段首逐字输入 `1. ` 自动开始编号；Enter 自动续号。Tab 将当前步骤放到前一个步骤下面，Shift+Tab 提升一级，子步骤回车继续同级编号；空项回车退出一层，顶层空项回车退出列表，Shift+Enter 只在当前项内换行。编号/无序/勾选列表均支持真实父子层级。
- `+` 新建便签，点标签切换，标签可拖动排序、双击快速改标题。标签快捷键默认关闭；设置中启用后，Ctrl+T 新建、Ctrl+Tab / Ctrl+Shift+Tab 切换，Ctrl+1～8 跳指定标签、Ctrl+9 到最后一张。
- 标签右侧 × 关闭标签；内容仍在“全部便签”里，可搜索标题再打开。启用标签快捷键后支持 Ctrl+W 关闭和 Ctrl+Shift+T 重开。本轮没有删除入口。
- 图片可直接粘贴、选择或拖入；点选图片后点“编辑信息”调整宽度、对齐、图注和替代文字，双击图片查看并单独缩放。
- 默认开启“自然缩进”：普通中文任务的 Tab/Shift+Tab 调整整段层级；Enter 延续当前缩进，行末中文/英文冒号后的 Enter 多缩进一级，空缩进行 Enter 退一级。两格全角空白为新缩进单位，已有半角/全角/Tab 前缀原样保留。可在设置关闭，恢复普通正文光标处 Tab 插入空白的基础行为；列表/表格/代码/标题仍沿原编辑语义，Shift+Enter 仍在块内换行。
- 单独输入 `---`、`***` 或 `___`，Enter 换段后显示分割线，点回可编辑源码；格式菜单的分割线仍使用原生富文本节点。
- 正文仍支持 `#`～`######` 六级标题；也可只写中文任务名，靠缩进建立父子关系，不必写数字或#。目录新工作台默认“智能层级”，包括标题、真实列表/任务和有缩进意图的连续段落组；可切回“仅标题”。没有任何缩进的普通散文不会全部塞入目录，已有空格不被自动改写。
- 顶部目录按钮打开侧栏，图钉选择常驻/临时显示，常驻与标签栏同层、共用背景，用细竖线分隔；拖动竖线调宽，偏好随本机工作台恢复。目录跟随当前编辑/滚动层级，点击定位；窄窗用覆盖显示保留正文宽度。
- 正文标题、含子步骤的列表/任务及缩进父段落左侧使用26px点击区和小SVG箭头，180ms内容收展、箭头平滑旋转；快速反向点击会衔接，系统减少动态效果时即时切换。子内容仍完整保存，折叠状态随便签恢复；目录跳转或光标进入隐藏子项会展开父级。
- 齿轮设置主题和字号，右下按钮或 Ctrl+加减号/Ctrl+滚轮按 4% 调整正文，Ctrl+0 恢复100%。图片预览中的缩放只作用图片。
- 齿轮 → 背景可选择本机图片（最大20 MiB），调整不透明度、模糊、填充方式和位置；移除只清背景，不删除正文图片。偏好和背景原图随本机试用快照恢复，不作为日记附件。
- 设置标题栏和底部“关闭 / 保存设置”固定在滚动内容之外。调整仍即时预览和自动保存，两个关闭入口及保存按钮都会等待当前草稿写入成功；失败留在窗口并提示。
- 原生窗口使用正常最小化/最大化/拉伸操作；图钉切换置顶。宿主按独立 profile 保留窗口位置、尺寸和置顶选择，真实多屏尚待实测。
- UI6置顶图钉移到原生灰色标题栏，与更大的最小化/最大化/关闭按钮并列；内容区明确从标题栏下方开始，四边四角保留resize区。移动/拉伸后350ms记忆窗口几何，最小化不覆盖此前最大化状态。字号/正文缩放仍在工作区快照中恢复。用户认可的宽窗透明/窄窗毛玻璃目录保留；灰色原生栏尚未开启系统级Mica，调研和回归边界见 [UI6验收](validation/2026-10-17-notes-frame-memory.md)。

## 草稿范围

输入会保存到独立试用区，标签、选区/光标、滚动和当前页一并恢复。切换标签期间保留各自撤销上下文，刷新或关闭重开后不保证撤销历史继续存在。

原生 profile 为 `D:\拾页\var\notes-ui-preview`，IndexedDB 名称为 `shiye-notes-ui-preview-v1`。浏览器直接访问 `http://127.0.0.1:18770/notes.html` 使用该浏览器自己的试用区，不与原生窗口共用草稿。

这只是前端恢复快照，尚不是选定的正式便签格式；不进入日记时间线、聊天归篇、日记统计、回忆、备份或同步。设置里的“导出全部草稿”可保存试用快照，原生宿主会打开“另存为”；本轮尚未提供导入 UI，也未实测完整原生导出流程。

出现保存错误或另一窗口冲突时，当前输入保留并明确标为未保存；先导出本窗口草稿，不能把该提示当作已经落盘。原生关闭需要页面确认保存完成，超时/失败保留窗口；异常退出的未落盘内容不承诺零丢失。

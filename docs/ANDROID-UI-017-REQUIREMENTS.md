- 编辑时跳动/闪烁、键盘唤起与收起生硬需要实际复现和优化；正文两侧边距均衡，可调，支持合适的两端对齐及字体粗细，兼容输入法、缩进、时间戳、图片和富文本原格式。
- 复制全文、TXT/PDF导出、移入回收站；可在工具栏配置常用操作，其余在设置内。导出使用现有正文/媒体/时间规则，PDF不将纯截图伪装为可用的文档导出，原文/编辑身份不随复制导出改变。

## 列表与分类

- 思绪列表整体用户目前满意，保留现布局。日历：选中日期深蓝圆；有日记、未选中的日期浅蓝圆，便于找日期；实际条目的本地日期与全局时区/筛选口径一致，空白未保存草稿不算已写日记。

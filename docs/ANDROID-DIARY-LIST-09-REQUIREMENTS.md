# Android 思绪列表进一步优化

2026-10-17 用户追加截图和“一本日记”参考页，并确认搜索采用**顶部图标，点击展开文字和日期筛选**。手机以随手写、快速回看为主，复杂统计留电脑；当前连续记录提示仅为轻量列表信息，不加入统计工作台。

- 去左上“思绪”大标题，紧凑日期／搜索／设置；搜索默认收起，可输入文字、日期或用系统日历选择，保留清除入口。
- 分类目录横向滑动，已有设置中支持新增、删除、改名、排序，按电脑契约保留身份；这些配置需要未来同步，不另造按名字重复的分类表。
- 思绪列表支持下拉刷新，去常驻刷新按钮；加载、完成、失败有轻反馈，空态也可拉，刷新保留筛选与滚动锚点。
- 按参考页使用浅底正文流、全宽多行摘要及细分隔线，元信息在每条底部。已有标题正常显示，无标题不重复大字“未命名日记”；日期、星期、时间、分类、已有地点按真实数据展示，缺项不编造。
- 连续记录天数与篇数在列表上方轻量显示，不从真实正文生成测试样本；当前设备日期与库日期差异记为适配边界，不改保存的事件时间。
- 日记置顶排前并加深背景，长按管理。电脑版已存在 `Entry.pinned:boolean`，只做本地保留式适配，不另造一份私有pinIds作为日记权威；带revision确认，不能让正文自动保存重置标记。
- 正文格式继续向电脑richdoc对齐；媒体缩略图只消费已有摘要/媒体索引，不为了列表UI另写正文拆分或扫描算法。尚无字段则明确待接。
- 思绪与电脑便签将来可能互通，**当前只保留需求，不提前把两个对象类型合并或迁移数据**。

算法最终在客户端、服务器或两者何处分工，用户明确**尚未决定**。先保证契约、唯一权威和可复用入口；后续以确认的部署方案实现，不把此前同步草案当作已选定的计算位置。本轮不扩展长文拆分、归篇和后台服务算法。

## 同轮追加：输入法与本地优先

用户确认：底部“会话／写日记／思绪”导航在输入法弹出时隐藏，收起后恢复，并有过渡动画；不能跟随键盘升到输入区上方。真正的编辑/发送工具栏仍需避让键盘。导航退场先离开布局，再在原屏底位置短淡出，恢复短淡入，快速反向切换取消旧动画，不留可点击的隐藏区域。

随想、思绪每次进入不应空白重载。先复用当前本地页面、列表、筛选和滚动，再后台静默刷新；只有首次创建页面加载资源。缓存命中不重建WebView、不reload，不以全屏loading或先清列表的方式刷新；显式刷新仍保留反馈，重复恢复请求合并。只保留一个随想WebView和一个思绪列表，Activity销毁释放，不建立无上限页面缓存。

后续互通的发送体验同样本地优先：本地消息立即显示，区分本地写入/待同步/服务器确认；持久队列后台发送、重试和幂等回执，不让网络阻塞输入。当前无联网和outbox，不将这条未来契约写成已经实现云发送，也不把仅内存乐观显示冒充已保存。

# 0.9.13 分类管理与图片粘贴

日期：2026-10-15。实施用户本轮明确的两项优先修复；其他未完成功能继续以 [需求复核](QUICK-REQUIREMENTS-AUDIT.md) 为准。

- 快捷窗入口：右上角“设置”→“分类与排序”→“分类与标签管理”。只调顺序也可在同一区域选择“调整分类顺序”，用上移/下移、首尾或指定序号，不必拖动。
- 修复快捷窗强制显示已隐藏正文，导致管理页挤在下半部。管理页现在占内容区，固定标题区域提供“返回日记”；列表/按钮聚焦时可 Esc 返回。输入框和下拉菜单内的 Esc 不强制导航，拖动中的首个 Esc 只取消拖动。
- 返回保留原篇，包括隐藏日记/草稿，不因普通列表过滤而跳到别篇。分类列表有独立滚动范围；排序/选择重绘保留滚动位置。
- 通用拖动模块识别最近可滚动祖先和实际可见边缘，靠近上下边缘持续滚动；列表到边界时可转交外层滚动。中部/边界外停止，drop/dragend/卸载停止并清理。仍使用原排序接口保存，内置图片拖动不误触文件上传。
- 粘贴图片弹出原有本地添加确认，默认聚焦“确认添加”。Enter 确认，← 选取消、→ 回确认，Esc 取消；调整压缩质量等控件时保留其正常方向键。组词及候选确认时不触发按钮默认 Enter。取消不上传、不改附件；关闭后恢复编辑焦点，释放本地预览 URL。

代码：`public/features/organization.js`、`public/app/main.js`、快捷窗样式；共享 `public/core/drag-scroll.js`/`drag-sort.js`；图片 `public/features/media-batch.js`。未改存储格式、旧日记或备份加密。
